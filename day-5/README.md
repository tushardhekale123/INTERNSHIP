# Day 5 - JavaScript & Employee Management Dashboard

## Objective

Learn JavaScript fundamentals, modern ES6 features, array methods, asynchronous programming, Fetch API, and REST API methods. Build an interactive Employee Management Dashboard using HTML, CSS, and JavaScript.

## JavaScript Exercises

Three JavaScript programs are included:

- `fundamentals.js` - Variables, objects, template literals, destructuring, spread operator, and arrow functions.
- `array_methods.js` - Map, filter, reduce, find, some, every, and sort methods.
- `api_methods.js` - Practice GET, POST, PUT, and DELETE requests using a test API.

## Employee Dashboard Features

- Display employee records and summary statistics.
- Search employees by name.
- Filter employees by department.
- Sort employee records.
- Add new employees.
- Edit existing employee details.
- Delete employee records.
- View employee details.
- Load employee data from a JSON file.
- Validate form inputs and handle errors.

## How to Run

1. Open the project folder in VS Code.
2. Open `employee-dashboard/index.html` using Live Server.
3. Run JavaScript exercises using the terminal:

```bash
node day-5/javascript/fundamentals.js
node day-5/javascript/array_methods.js
node day-5/javascript/api_methods.js
```

An internet connection is required for the API exercise.

## Learning Outcomes

- Understand JavaScript fundamentals and ES6 features.
- Work with arrays and objects.
- Use DOM manipulation and event handling.
- Load and process JSON data.
- Understand Fetch API and async/await.
- Practice REST API methods.
- Build an interactive web application.

## Limitations

Employee changes are stored temporarily in memory and reset when the page is refreshed. The API exercise uses JSONPlaceholder for testing; its changes are not permanently saved.

## Conclusion

Day 5 provided practical experience with JavaScript, API requests, data handling, and building an interactive Employee Management Dashboard.
