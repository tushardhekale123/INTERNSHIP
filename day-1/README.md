To strengthen programming fundamentals, problem-solving skills, and basic Data Structures and Algorithms.

## Topics Covered

- Programming Fundamentals
- Arrays
- Stack
- Queue
- Hash Map / Dictionary
- Set
- Searching and Sorting
- Recursion
- Time and Space Complexity
- Git and GitHub
